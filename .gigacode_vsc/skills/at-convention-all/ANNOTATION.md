# Аннотация: at-convention-all

**Универсальный сборщик «проектной разведки» тестового проекта → контекст для генерации автотестов.**

## Назначение

`at-convention-all` — фреймворк-агностичный скилл, который анализирует **любой** тестовый
проект, автоматически определяет используемый тестовый фреймворк и собирает факты и
конвенции о кодовой базе в единый структурированный Markdown-отчёт
(`<имя-проекта>-project-intelligence.md`). Отчёт предназначен для последующего использования
другим агентом генерации, чтобы автотесты создавались под реальные паттерны проекта.

## Ключевые возможности

- **Автоопределение фреймворка** — Playwright / Cypress / Jest / Vitest и др.
  (по конфиг-файлам и `package.json`); поддержка монорепо/Nx.
- **Сбор фактов из кода** — структура проекта, конвенции именования, локаторы, ассерты,
  фикстуры, хуки, тестовые данные, CI/CD, артефакты, setup/аутентификация, теги.
- **Прогрессивное раскрытие** — лёгкий `SKILL.md` + детальные `references/` справочники.

## Принципы

- **Только факты** — каждый пример сопровождается путём к файлу, ничего не выдумывается.
- **«Не обнаружено»** — отсутствующие паттерны помечаются, без шаблонных заглушек.
- **Без привязок к продукту** — нет захардкоженных путей, правил или тегов конкретного проекта.
- **Не изменяет код** — только создаёт новый файл отчёта.

## Как использовать

```
/skill at-convention-all            # запуск
# → указать путь к тестовому проекту (Enter = текущий каталог)
✅ Файл <имя>-project-intelligence.md создан
```

## Структура скилла

```
at-convention-all/
├── ANNOTATION.md                  — этот файл (аннотация)
├── SKILL.md                       — описание и алгоритм работы
├── README-quickstart.md           — быстрый старт + пример выходного отчёта
└── references/
    ├── framework-detection.md     — матрицы определения фреймворков
    ├── report-template.md         — шаблон отчёта (19 разделов)
    └── generic-collection.md      — техника сбора фактов по разделам
```

## Выходной отчёт (19 разделов)

Мета и версии · Фреймворк и конфиги · Структура проекта · Запуск и скрипты · Именование ·
Стиль и линт · Локаторы · POM · Фикстуры · Ассерты · Таймауты · Тестовые данные · Хуки ·
Setup/аутентификация · Теги · CI/CD · Артефакты · Эталонный тест · Выводы для генератора.
